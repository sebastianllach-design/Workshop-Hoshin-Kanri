# Publicación en GitHub y Render

## GitHub

1. Reemplazar el contenido del repositorio por los archivos de esta carpeta.
2. Confirmar que `index.html` quede en la raíz.
3. Subir todos los recursos gráficos incluidos.
4. Publicar los cambios con la versión `v52`.

## Render

Para un sitio estático conectado al repositorio:

- **Build Command:** dejar vacío.
- **Publish Directory:** `.`

Después del despliegue, abrir la aplicación y confirmar que la portada muestre **Versión v52 · Evaluación y podio**.

## Verificación recomendada

1. Abrir la Hoja 6 **Evaluación y podio**.
2. Presionar **Cargar los 3 ejemplos**.
3. Confirmar que **Sistema alineado** aparezca como ganador.
4. Confirmar el orden y la escala visual de los puestos 1.º, 2.º y 3.º.
5. Modificar una valoración humana y comprobar que la tabla se reordene cuando corresponda.
