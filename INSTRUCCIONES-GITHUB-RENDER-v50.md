# Publicación de la v50

1. Descomprimir el paquete ZIP.
2. Reemplazar en la raíz del repositorio los archivos anteriores por todos los archivos incluidos.
3. Confirmar que `index.html` quede en la raíz.
4. Realizar commit y push en GitHub.
5. Si Render no inicia el despliegue automáticamente, utilizar **Manual Deploy → Deploy latest commit**.

## Verificación rápida

- La portada debe indicar **Versión v50 · Contador de consultas centrado**.
- El índice debe mostrar **Hoshin Workshop · v50**.
- En la Hoja 2, el texto **Consultas realizadas: 0/3** debe verse centrado dentro del indicador.
- El contador debe actualizarse normalmente al realizar consultas.

El paquete contiene archivos completos; no es necesario editar líneas individuales.
