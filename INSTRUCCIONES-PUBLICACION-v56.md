## Prueba mínima después del despliegue

1. Entrar a `/facilitator.html`.
2. Crear una experiencia temporal sin equipos.
3. Seleccionarla y pulsar **Eliminar experiencia**.
4. Cancelar la primera vez y confirmar que la experiencia continúa.
5. Repetir, escribir un código incorrecto y confirmar que no se elimina.
6. Repetir con el código correcto y comprobar que desaparece de la lista.

Para no arriesgar datos reales, la prueba debe realizarse únicamente con una experiencia temporal creada para este fin.
